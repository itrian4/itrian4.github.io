Power BI · Ventas

Dashboard de Ventas y KPIs Comerciales

Tablero interactivo que consolida datos de ventas regionales, comparativos vs presupuesto y análisis de tendencias mensuales para la toma de decisiones gerenciales.

DAX Power Query SQL Server KPIs
  • Modelo de datos estrella con 5 tablas de dimensiones
  • Medidas DAX: YTD, MoM%, Variación vs Presupuesto
  • Segmentadores dinámicos por región, producto y periodo
  • Mapa geográfico de distribución de ventas
  • Tooltip personalizado con mini-KPIs
Fuente de datos: SQL Server / Excel exportado. ETL en Power Query con limpieza, normalización de fechas y cruce de tablas. Publicado en Power BI Service con actualización programada cada 24 h.

El tablero reveló que el 68 % de las ventas se concentra en 3 regiones. Se identificó una caída sistemática en Q3 atribuida a estacionalidad. Las medidas DAX redujeron el tiempo de reporte semanal de 4 h a 15 min.

Power BI · RRHH

Análisis de Recursos Humanos

Dashboard de indicadores de talento humano: rotación, ausentismo, headcount por área y análisis de desempeño. Integrado con SharePoint como fuente de datos.

SharePoint DAX Power Query RRHH
  • Indicador de tasa de rotación mensual
  • Gráfico de pirámide demográfica por área
  • Matriz de desempeño con formato condicional
  • Alertas visuales de ausentismo crítico
  • Filtros cruzados departamento / cargo / periodo
Datos extraídos de listas de SharePoint vía conector nativo. Transformaciones en Power Query. Modelo relacional de 3 tablas. Acceso controlado por roles (RLS).

Rotación del 18 % en área operativa, 6 puntos sobre el benchmark del sector. Ausentismo pico los lunes (23 % más que el promedio). Insights que impulsaron revisión de la política de bienestar laboral.
